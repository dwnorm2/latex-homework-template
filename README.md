# latex-homework-template

A minimal LaTeX template for homework assignments.

## Requirements

- TeX Live
- latexmk
- VS Code with LaTeX Workshop (optional)

## Structure

- `assignment.tex` - Main LaTeX document
- `figures/` Images and figures used in the assignment

## Compile

Compile with:

```bash
latexmk -pdf assignment.tex
```

## Figures

Just create an empty directory:

```bash
mkdir figures
```
